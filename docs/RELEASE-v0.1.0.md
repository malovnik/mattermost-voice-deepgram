Первая версия плагина голосовых сообщений для команды.

- Запись, прослушивание, скачивание и добавление аудио в обычный черновик Mattermost.
- Автоматическая расшифровка через Deepgram Nova-3/Nova-2, русский/английский/автоопределение.
- Ответы в исходной ветке, включая личные сообщения; повтор после ошибки через меню или `/voice`.
- Секретный ключ только на сервере, очередь с восстановлением и ограничением повторных расходов.
- Linux amd64/arm64; минимальная версия Mattermost 10.11.

Установка: System Console → Plugins → Upload Plugin → выбрать `.tar.gz` → Enable → указать Deepgram API key в настройках плагина. Архив не распаковывать. Контрольная сумма — в SHA256SUMS.

Запись работает и без ключа. Нативный мобильный клиент не поддерживает UI веб-плагина: аудио можно прикрепить из диктофона, серверная расшифровка работает.

Реальный ключ Deepgram и сервер команды ещё не подключены. Проверка с ними остаётся шагом установки. Автотесты используют изолированный HTTPS-эмулятор Deepgram.

Подробные инструкции и границы проверки — README и docs/VALIDATION.md.

Проверено: [зелёный CI](https://github.com/malovnik/mattermost-voice-deepgram/actions/runs/36000557970), включая установку на настоящий Mattermost 10.11.0 и весь путь транскрибации через HTTPS-эмулятор.
