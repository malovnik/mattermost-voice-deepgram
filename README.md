# Voice Messages · Deepgram для Mattermost

Запись голосовых сообщений прямо в Mattermost и автоматическая расшифровка опубликованного аудио через Deepgram. Приватный плагин команды, интерфейс на русском.

## Установка

1. Скачайте `com.malovnik.voice-deepgram-0.1.0.tar.gz` из **Releases** этого репозитория. Распаковывать не нужно.
2. В Mattermost откройте **System Console → Plugins → Plugin Management → Upload Plugin**, загрузите архив и включите **Voice Messages · Deepgram**.
3. В настройках плагина укажите **Deepgram API key** и сохраните. По умолчанию: Nova-3, русский язык, global endpoint, до 25 МиБ на файл, запись до 5 минут.
4. Обновите клиент. Скрепка возле поля сообщения → **Голосовое сообщение** → **Начать запись**. Разрешите микрофон, остановите, прослушайте, нажмите **Добавить к сообщению**, затем штатную кнопку отправки Mattermost.
5. Аудио остаётся обычным вложением вашего сообщения. Бот **Расшифровка аудио** публикует текст в той же ветке. Для сообщения, уже написанного в ветке, ответ приходит в эту же ветку со ссылкой на источник.

Нужен Mattermost **10.11+**, сервер Linux amd64 или arm64, доступ сервера к HTTPS Deepgram и включённые плагины, загрузка файлов и bot accounts. Если загрузка плагинов отключена, администратор включает `PluginSettings.EnableUploads` в конфигурации своего сервера. HTTPS нужен для микрофона; localhost подходит для разработки. Разрешения на файлы и ограничения сервера продолжает проверять Mattermost.

**Ключ пока не нужен для записи.** Без него новые сообщения не ставятся в очередь. После подключения старые записи можно расшифровать вручную. Ключ вводится только в секретное поле System Console; браузер и репозиторий его не получают.

## Что поддерживается

| Клиент / возможность | Поведение |
| --- | --- |
| Веб-клиент, Chrome / Edge / Firefox | Запись через MediaRecorder, обычно WebM/Opus или Ogg/Opus |
| Safari | Запись M4A/MP4 при поддержке MediaRecorder |
| Mattermost Desktop | Веб-плагин; нужен доступ приложения и ОС к микрофону |
| Нативный Mattermost iOS / Android | UI веб-плагинов не поддерживается; прикрепите файл из диктофона, сервер расшифрует его |
| Каналы, личные сообщения, ветки | Штатные вложения и ответ в исходной ветке |
| Без Deepgram / при сбое | Аудио отправляется независимо; при ошибке обработки бот сообщает о возможности повторить |

Поддерживаемые вложения: WebM, Ogg, Opus, M4A, MP3, WAV, FLAC, AAC. В WebM распознаётся аудиодорожка. **Одно сообщение — первое подходящее аудиовложение**; несколько записей отправляйте отдельными сообщениями. Размер проверяется до отправки провайдеру. Лимит длительности действует на рекордер, а не на загружаемые извне файлы. Длинные внешние записи могут не уложиться в тайм-аут 90 секунд. Текст длиннее 14 000 символов сокращается с пометкой.

## Повторная расшифровка

- Меню собственного сообщения с файлом → **Расшифровать аудио**.
- Или `/voice transcribe POST_ID`, где POST_ID — последний фрагмент постоянной ссылки на сообщение (26 символов).
- `/voice` показывает справку, в том числе в мобильном приложении.

Запрос может сделать автор или системный администратор, состоящий в канале. Готовая расшифровка повторно не оплачивается. При повторе после ошибки бот обновляет прежнее сообщение с ошибкой. Распознавание тишины считается успешным и сообщает «Речь не обнаружена».

## Настройки и данные

- `TranscribeAllAudio` включён по умолчанию: обрабатываются новые аудиовложения из всех клиентов, в том числе в личных и закрытых каналах. При выключении автоматически обрабатываются только имена `voice-message-*` из рекордера. Это фильтр удобства, а не граница доверия: пользователь может переименовать файл.
- Язык: русский, английский или автоопределение доминирующего языка. Модель: Nova-3 или Nova-2. Регион: Global или EU.
- Deepgram получает только бинарное содержимое выбранного аудио; пароли Mattermost, cookies, имена каналов и соседние сообщения не отправляются. Используется `mip_opt_out=true`.
- Записанный черновик живёт в памяти браузера; Deepgram получает его только после публикации. При закрытии окна локальная запись удаляется; её можно предварительно скачать.
- Аудио и текст хранятся в Mattermost согласно его политике хранения. Ответ бота — отдельное сообщение: при удалении исходного сообщения в ветке удаляйте и его расшифровку, если она не удалена самим Mattermost.
- Очередь в plugin KV содержит ID сообщения, счётчик попыток и срок блокировки, без аудио и транскриптов. При перезапуске работа восстанавливается; аварийно прерванная задача ждёт до 3 минут. Завершённые задачи удаляются из очереди.
- На один процесс плагина одновременно выполняется одна задача. CAS-блокировка не даёт узлам кластера одновременно брать одну задачу. Повторы сетевых ошибок, HTTP 429 и 5xx: максимум 3 попытки, паузы 15 и 60 секунд. Ошибки ключа не повторяются автоматически. После трёх попыток обработка больше не вызывает Deepgram; доставка сообщения об ошибке прекращается после шестой попытки и отмечается в журнале администратора.
- Перед публикацией результата повторно проверяются исходное сообщение, членство автора и архивирование канала. Текст не исполняется как HTML, Markdown экранируется, упоминания нейтрализуются.
- Строгая exactly-once оплата внешнего API не гарантируется: авария после ответа Deepgram и до сохранения в Mattermost может привести к повторному запросу. Проверка существующего ответа предотвращает обычные дубли; остаётся узкое окно сбоя между публикацией и фиксацией на стороне сервера.

## Сборка и проверка

Требуются Go 1.26.8+, Node.js 22, npm, tar. Linux-бинарники собираются кросс-компиляцией, без CGo.

```sh
make install
cd webapp && npx playwright install chromium && cd ..
make test
make bundle
```

В `dist/` появятся установочный архив и `SHA256SUMS`. CI повторяет проверки на чистом Linux и сохраняет архив как artifact. Локальные тесты используют подменённый Deepgram и Mattermost Plugin API; CI также устанавливает реальный Mattermost и выполняет цепочку с изолированным HTTPS-сервером, имитирующим Deepgram; браузерные тесты записывают настоящий WebM через виртуальный микрофон Chromium. Производственные сервисы и ключ для тестов не нужны.

Результаты и границы проверки: [docs/VALIDATION.md](docs/VALIDATION.md). Устройство и официальные источники: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

Перед использованием командой остаётся короткая приёмка на вашем сервере: загрузка архива, включение, 10–20 секунд русской речи, прослушивание вложения и проверка расшифровки в канале и личном сообщении. Без адреса сервера и ключа эта проверка не выполняется.
